# 💻 Projeto Portfólio - Exercício Senac

Este é um projeto de página de portfólio desenvolvido durante as aulas práticas no **Senac**, com o objetivo de fixar os conceitos fundamentais de desenvolvimento web Front-end.

---

## 🎯 Objetivo do Projeto
Praticar e aplicar na prática os conceitos de estruturação semântica, estilização e criação de layouts responsivos para a web.

---

## 🛠️ Tecnologias Utilizadas
- **HTML5** (Estrutura semântica)
- **CSS3** (Estilização e Flexbox)

---

## 📌 Funcionalidades
- [x] Apresentação pessoal e objetivo profissional.
- [x] Seção de exibição de projetos.
- [x] Links de contato e redes sociais.
- [x] Design responsivo (adaptado para telas de celular e computador).
